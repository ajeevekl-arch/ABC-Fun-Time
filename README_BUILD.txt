ABC FUN TIME - Android APK Project

This project wraps the supplied Netlify ABC Playlist website as a standalone Android app.

Website:
https://resplendent-phoenix-42aa97.netlify.app/

Important:
- The app loads the live Netlify site, so the website/Netlify deployment must remain online.
- The YouTube API key is NOT stored in this Android project. It remains on Netlify as YOUTUBE_API_KEY.
- Open the project in Android Studio.
- Build > Build App Bundle(s) / APK(s) > Build APK(s).
- The debug APK will normally be in:
  app/build/outputs/apk/debug/app-debug.apk

If Android Studio is not installed, Android Studio must be installed once to compile this project.
